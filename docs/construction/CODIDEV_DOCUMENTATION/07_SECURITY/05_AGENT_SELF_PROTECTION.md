# CodiDev Self-Protection

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

CodiDev must protect itself against tool abuse, policy bypass, memory poisoning, skill poisoning, connector abuse, tenant breakout, malicious project content, supply-chain attacks and excessive agency.

The LLM is not the security authority.

## Implementation note

This document is part of the CodiDev documentation corpus. It defines behavior and boundaries for the corresponding subsystem and must be read together with the neighboring documents.
