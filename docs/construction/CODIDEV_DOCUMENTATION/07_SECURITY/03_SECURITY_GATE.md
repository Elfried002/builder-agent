# Security Gate

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Default security gate:

CRITICAL → BLOCK
HIGH → BLOCK or REVIEW
MEDIUM → REVIEW/WARNING
LOW → WARNING
INFO → INFORMATIONAL

Natural-language prompts must not bypass the gate.
