# Threat Model

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Threats include direct and indirect prompt injection, excessive agency, sensitive information disclosure, supply-chain attacks, malicious repositories, memory poisoning, skill poisoning, cross-tenant leakage, secret leakage, insecure output handling, resource exhaustion, unauthorized deployment and malicious MCP responses.

Project-controlled content must be treated as potentially hostile.

## Implementation note

This document is part of the CodiDev documentation corpus. It defines behavior and boundaries for the corresponding subsystem and must be read together with the neighboring documents.
