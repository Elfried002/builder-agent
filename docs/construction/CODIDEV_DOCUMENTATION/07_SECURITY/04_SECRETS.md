# Secrets Management

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Never store secrets in memory, skills, source control, ordinary logs or task descriptions.

Connector credentials require secure storage and strict scope. Logs and evidence must redact secrets.
