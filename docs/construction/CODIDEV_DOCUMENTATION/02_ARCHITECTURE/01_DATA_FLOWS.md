SOURCE → DATA → TRUST LEVEL → CONTEXT → LLM/RULES → TOOL REQUEST → IDENTITY → TENANT → PROJECT → RISK → POLICY → APPROVAL → ACTION → VERIFICATION → EVIDENCE → MEMORY/LEARNING

Every important external action follows this controlled path.
