# Decision Flow

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Request → intent → requirements → context → constraints → options → risk → policy → decision → execution → verification.

The LLM may propose; policy and authorization decide. User-facing explanations should expose structured rationale and evidence, not private chain-of-thought.
