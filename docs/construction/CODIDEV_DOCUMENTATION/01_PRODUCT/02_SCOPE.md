# Scope and Boundaries

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

In scope: agentic software engineering, controlled code execution, GitHub, Supabase, Vercel, MCP/connectors, security, memory, learning and tenant personalization.

Out of scope: Hermes as production runtime, the separate multi-agent orchestrator, Telegram, uncontrolled infrastructure access, automatic foundation-model retraining and silent production changes.

## Implementation note

This document is part of the CodiDev documentation corpus. It defines behavior and boundaries for the corresponding subsystem and must be read together with the neighboring documents.
