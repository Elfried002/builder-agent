# Error and Failure Handling

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Distinguish NOT_EXECUTED, BLOCKED, FAILED, WAITING_FOR_USER, EXECUTED and VERIFIED.

Errors retain evidence and actionable context. Never convert failure into success.
