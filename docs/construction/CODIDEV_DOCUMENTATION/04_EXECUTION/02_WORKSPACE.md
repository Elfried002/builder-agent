# Workspace and Sandboxing

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Project code is untrusted. Workspace isolation must cover filesystem, commands, processes, network, secrets and project resources. Repository scripts must not execute with unrestricted host privileges.
