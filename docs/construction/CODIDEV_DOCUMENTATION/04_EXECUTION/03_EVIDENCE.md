# Evidence Model

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Evidence should record operation, status, actor, tenant, project, tool, resource, commands, files, tests, security results, errors, warnings, external IDs and validation.

A result is VERIFIED only when its verification criteria pass.
