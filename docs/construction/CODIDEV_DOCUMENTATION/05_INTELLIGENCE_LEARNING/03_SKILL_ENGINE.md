# Dynamic Skill Engine

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

A dynamic skill is reusable guidance generated from validated experience. It contains identity, scope, purpose, rules, evidence, confidence, version, status, source and validation history. A skill can never grant permissions or bypass security.
