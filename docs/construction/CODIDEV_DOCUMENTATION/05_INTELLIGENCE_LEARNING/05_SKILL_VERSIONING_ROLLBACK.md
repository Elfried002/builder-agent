# Skill Versioning and Rollback

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Skill lifecycle:

OBSERVED → CANDIDATE → EVALUATING → ACTIVE → REINFORCED → DEPRECATED/ROLLED_BACK

A degraded skill is deactivated, rolled back and recorded as a learning failure.
