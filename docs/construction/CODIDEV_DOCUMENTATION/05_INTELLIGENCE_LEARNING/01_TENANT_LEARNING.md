# Tenant Learning

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Every tenant has an isolated learning space containing preferences, patterns, skills and feedback. Private tenant learning must never leak into another tenant or become global knowledge automatically.
