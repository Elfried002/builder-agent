# Security Test Plan

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Mandatory scenarios include direct prompt injection, indirect injection via README/comments, malicious package metadata, malicious MCP output, secret leakage, unauthorized tool calls, cross-tenant access, memory poisoning, skill poisoning, excessive agency and destructive actions without approval.

## Implementation note

This document is part of the CodiDev documentation corpus. It defines behavior and boundaries for the corresponding subsystem and must be read together with the neighboring documents.
