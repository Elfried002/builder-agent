# CodiDev — Documentation Hub

This archive is the structured documentation corpus for the CodiDev agentic software-engineering system.

CodiDev is one unified product. Hermes is used to construct the agentic core; Hermes is not the final runtime dependency.

## Major boundaries

- No external multi-agent orchestrator.
- No Telegram.
- Supabase is the intended SaaS persistence/authentication layer.
- GitHub, Supabase and Vercel are initial connectors.
- Security, evidence, memory and adaptive learning are first-class capabilities.
- Learning is tenant-scoped and reversible.
