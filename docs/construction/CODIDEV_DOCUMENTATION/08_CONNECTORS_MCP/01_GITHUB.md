# GitHub Connector

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

GitHub connector capabilities: connect account, list repositories, import repositories, inspect branches, create branches, commit, push, inspect pull requests and create pull requests when authorized.

Remote writes pass policy, security and audit controls.
