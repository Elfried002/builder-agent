**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

Task states:

DRAFT → ANALYZING → PROPOSED → WAITING_FOR_USER → IN_PROGRESS → BLOCKED/FAILED → EXECUTED → VERIFYING → VERIFIED → READY → COMPLETED/CANCELLED

Significant task transitions should be observable.
