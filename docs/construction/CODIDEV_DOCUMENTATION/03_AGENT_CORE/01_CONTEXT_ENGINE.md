# Context Engine

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Context layers: SYSTEM, TENANT, USER, PROJECT, TASK, SESSION, EXTERNAL_DATA, TOOL_RESULTS and LEARNED_KNOWLEDGE.

Every context item should have provenance, scope and trust classification. Cross-tenant context is forbidden.
