# Data Architecture

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Supabase is the intended SaaS persistence/authentication layer.

Conceptual entities include users, profiles, organizations, organization_members, projects, project_members, conversations, messages, tasks, task_events, files, deployments, connector_accounts, security_findings, audit_logs, usage, memory_items, learned_preferences, learned_skills, skill_versions, feedback and evaluations.
