# Deployment Engine

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

Deployment flow:

Ready → Policy → Approval → Git validation → Security gate → Deploy → Status → Health Check → Evidence → Verified

CodiDev deploys user projects; CodiDev itself is not the deployment target described here.
