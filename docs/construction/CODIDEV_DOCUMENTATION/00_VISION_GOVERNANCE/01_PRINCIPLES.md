# Core Principles

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

1. Proof over assertion.
2. Real execution over simulation.
3. Verification over confidence.
4. Policy over LLM intention.
5. Security by design.
6. Least privilege.
7. Tenant isolation.
8. Explicit provenance.
9. Human gates for critical actions.
10. No silent scope expansion.
11. No secrets in normal memory.
12. Learning must be reversible.
13. Skills are guidance, never authority.
14. Current explicit instructions outrank historical preferences.
15. A failed or blocked action is never reported as successful.
