# Architectural Decisions Register

**Version:** 1.0  
**Project:** CodiDev  
**Repository:** `github.com/Elfried002/codidev`

---

ADR-001: CodiDev is one unified product/repository.
ADR-002: Hermes is the construction environment, not the CodiDev runtime.
ADR-003: The separate Multi-Agent Orchestrator is excluded.
ADR-004: Telegram is excluded.
ADR-005: Supabase is the intended SaaS persistence/authentication platform.
ADR-006: GitHub, Supabase and Vercel are initial connectors.
ADR-007: Learning is behavioral and evidence-based, not uncontrolled model-weight training.
ADR-008: Authorization and policy are authoritative outside the prompt.

## Implementation note

This document is part of the CodiDev documentation corpus. It defines behavior and boundaries for the corresponding subsystem and must be read together with the neighboring documents.
