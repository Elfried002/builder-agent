The current repository contains an agent-oriented structure with agent/, docs/, memory/, scripts/, skills/, tests/, workspace/, AGENT_SPEC.md, DESCRIPTION.md, SKILL.md and SOUL.md.

The existing Builder Agent documentation describes Hermes runtime and legacy orchestrator integration. The target CodiDev architecture supersedes those runtime assumptions while preserving useful ideas such as proof-based execution, governance, skills, memory, testing and DevSecOps.

Migration principle:

current agent definition → preserve useful concepts → remove obsolete runtime/orchestrator assumptions → build independent CodiDev core → integrate product capabilities in the same repository.
